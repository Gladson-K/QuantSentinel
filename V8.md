# V8: Ask (Cited Q&A Agent and What-If Simulation)

**Problem fixed:** People ask "why did we choose X?" and "what happens if we reverse Y?" and get opinions instead of evidence.

## New features
1. **Ask DecisionGraph:** natural-language Q&A over the graph with mandatory citations to decisions and sources; refuses when evidence is missing.
2. **Timeline answers:** "how did our database strategy evolve?" returns a dated chain with supersessions.
3. **What-if / impact analysis:** select a decision to reverse or change; see dependent decisions, broken assumptions, affected teams, and related open work.
4. **Draft decision assistant:** helps write a new decision record, pre-filled with prior art, conflicts and suggested reviewers.
5. **Onboarding briefs:** auto-generated "decisions you should know" for a new member of a team or project.

## Design
```
Question -> Intent Router (lookup | timeline | impact | draft)
  lookup:   hybrid retrieval (BM25 + vectors + graph expansion) -> reranker -> LLM answer with citations
  timeline: graph walk ordered by date -> summarizer
  impact:   Impact Resolver (V6) + tickets/PR links -> ranked report
  draft:    template + related decisions + conflict check (V4)
Answer Verifier: every claim must map to a retrieved evidence id, else removed
```
- **Citation enforcement:** answer schema `{claims:[{text, evidence_ids[]}]}`; claims without evidence are dropped; UI shows source snippets.
- **Access control in retrieval:** filter by user permissions *before* retrieval, never after generation.
- **Simulation:** deterministic graph computation (no LLM) for impact; the LLM only narrates results.

## Implementation steps
1. Hybrid retrieval service with reranking.
2. Answer verifier and refusal policy ("not enough evidence").
3. Impact analysis API and UI (blast radius view).
4. Draft assistant UI in the web app and Slack.
5. Evaluation set of 300 real questions with gold evidence.

## Metrics
Citation validity 100%, answer groundedness >= 95% (human audit), refusal precision, user-rated helpfulness, time saved vs. manual searching.

## Risks
Hallucinated reasoning (verifier plus refusal), leaking restricted decisions (pre-retrieval ACL), over-trust (show confidence and sources always).
