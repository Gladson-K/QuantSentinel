# V9: Enterprise (Multi-Tenant, Compliance, On-Prem)

**Problem fixed:** Large organizations need security, governance, data residency, and deployment control before they can adopt.

## New features
1. **Multi-tenant SaaS and single-tenant / on-prem (Kubernetes, Helm chart, air-gapped option).**
2. **SSO/SAML/OIDC, SCIM provisioning**, fine-grained roles, custom policies.
3. **Audit and compliance:** immutable audit log, evidence export, retention rules, legal hold, SOC 2 / ISO 27001 control mapping.
4. **PII and secret redaction** before storage and before any model call; configurable detectors.
5. **Bring-your-own-model and keys (BYOK/KMS)**, region pinning, private model endpoints.
6. **Approval workflows** for regulated decisions (two-person rule, signed approvals).
7. **Admin console:** usage, cost controls, connector governance, data deletion requests.

## Design
- **Tenancy:** shared control plane, data plane per tenant (schema-per-tenant or database-per-tenant for large clients), tenant id enforced in a request context and row-level security.
- **Encryption:** TLS everywhere, per-tenant data keys wrapped by KMS, field-level encryption for sensitive text.
- **Redaction pipeline:** detectors (regex, NER) -> tokenization with reversible vault for authorized viewers -> only redacted text leaves the boundary.
- **Audit:** append-only store with hash chaining; export in standard formats.
- **Deployment:** Helm charts, Terraform modules, health probes, blue/green upgrades, backup and restore drills.
- **Reliability:** SLOs (99.9% API), multi-AZ, queue backpressure, disaster recovery with RPO/RTO targets.

## Implementation steps
1. Introduce tenant context and RLS tests (cross-tenant access must fail).
2. SSO/SCIM, then policy engine (OPA-style) for authorization.
3. Redaction service with evaluation on labeled PII data.
4. Audit chain and export tooling.
5. Packaging for on-prem; run a penetration test and remediate.

## Metrics
Zero cross-tenant leaks in tests and pentest, redaction recall >= 99% on test set, upgrade success rate, mean time to restore.

## Risks
Operational complexity (invest in automation), slow sales cycles (design partner approach), model data-handling concerns (default to no training on customer data and offer local models).
